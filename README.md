## 📖 站点简介

本项目为 **每天听本书** 知识体系的 GitHub Pages 部署发布产物仓库。

收录了商业财经、心理学、个人成长、科技互联网、历史哲学等多个领域的精选图书万字拆解与思维模型，通过现代化的 VitePress 静态站点引擎驱动，提供秒级搜索与舒适的沉浸式阅读体验。

- 🌐 **在线阅读地址**：[https://dedaox.feyoudao.cn](https://dedaox.feyoudao.cn)
- 💻 **文档源码仓库**：[qqlcx5/vitepress-dedao](https://github.com/qqlcx5/vitepress-dedao)

---

## 🛠️ 技术架构

- **静态渲染引擎**：VitePress 现代静态文档生成器
- **快速交互响应**：极致轻量的单页水合（Single Page Hydration）与极速全文检索
- **自动化持续集成**：通过 GitHub Actions 将源码仓库自动编译并同步推送到本仓库
- **域名解析与加速**：绑定自定义域名并配置 CDN 加速访问
